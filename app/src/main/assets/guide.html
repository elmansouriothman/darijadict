📚 How to Use the App - Moroccan Darija

🧭 1. Main Screens Overview

The App is divided into 4 main screens:

  • Guide
  • Dictionary
  • Lists
  • Grammar

You are now in the Guide screen and you are about to learn how to use the many functions the app has to offer.

This screen also has a button for Recommended Links that I encourage you to check.

🔎 2. Dictionary Screen

On the Dictionary screen, you will find a search bar with a dropdown button that allows you to search for words from:

  • All categories
  • Only in Darija
  • Only in English
  • Using Arabic script

Below the search bar, you will find cards showing:

  • Darija vocabulary (Latin script)
  • Arabic script version
  • English meaning

Each card has two buttons:

  • Save vocabulary
  • Add to personal lists

If you click a card, you will see a detailed screen with:

  • Blue speaker icon for pronunciation
  • English meaning
  • Word forms: plural, present stem, feminine and masculine forms
  • Example usage sentence

📝 3. Lists Screen

On the Lists screen, you will find:

  • A New List button to create custom lists
  • A Download button to get the Anki Deck Note Template

Inside your lists:

  • View saved words
  • Export words for Anki study

Also access your Saved list easily!

📚 4. Grammar Screen

The Grammar screen contains all the lessons you should follow, from easiest to hardest, in the recommended order.

🎯 5. How to Study Vocabulary on Anki

Follow these steps to study your vocabulary using Anki:

  1. Install Ankidroid (or Anki Desktop) on your device.
  2. Download the Anki Deck Note Template (.apkg) and open it with Anki.
  3. Export your personal list from the app (.txt file).
  4. In Anki, choose Import File and select your .txt file.
  5. During import:
    • Enable HTML import.
    • Set Note Type to Moroccan Darija.
    • Select your preferred deck.
    • Map fields from 1 to 13 sequentially.
    • Set the Tags field to (Nothing).
  6. Click Import to finish!
